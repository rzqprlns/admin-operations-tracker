# Admin Operations Tracker

An Excel-based administrative operations tracker designed to simulate how administrative records can be validated, monitored, and summarized for day-to-day operational reporting.

> **Project Type:** Self-initiated portfolio project using synthetic administrative data.

## Overview

Administrative work is not only about entering data. Records also need to be standardized, checked for completeness, monitored against deadlines, and summarized into information that can be used for follow-up.

This project simulates an administrative workflow for tracking incoming documents from the moment they are received until they are completed.

The workbook contains **120 synthetic administrative records** and an operational monitoring dashboard.

## Workbook Structure

### 1. Admin Tracker

The main operational table contains:

- Record ID
- Received Date
- Document Type
- Requester
- Owner / PIC
- Priority
- Status
- Due Date
- Completed Date
- Processing Days
- SLA Days
- SLA Status
- Document Completeness
- Duplicate Flag
- Notes

### 2. Dashboard

The dashboard summarizes operational indicators including:

- Total records
- Completed records
- Open backlog
- SLA compliance
- Pending verification
- Incomplete records
- Escalated records
- Missing documents
- Duplicate records
- Records handled by each owner
- Completion by owner
- Records by status

### 3. Lists

Reference values are stored separately to support standardized dropdown inputs for status, priority, owner, and document type.

## Excel Features Used

### Data Validation
Dropdown lists help standardize administrative inputs and reduce inconsistent categories.

### Formula-Based Monitoring
Processing time and SLA status are calculated automatically from received, due, and completion dates.

### Conditional Formatting
Operational exceptions such as high-priority records, overdue items, missing documents, and duplicate records are visually highlighted.

### Data Quality Checks
The tracker includes explicit fields for document completeness and potential duplicate records.

### Dashboard & KPI Reporting
Operational records are summarized into KPIs and status monitoring to make backlog and follow-up priorities easier to identify.

## Example Business Questions

This workbook can help answer questions such as:

- How many administrative records are still open?
- Which records require verification or follow-up?
- Are there incomplete or duplicate records?
- Which records have exceeded their SLA?
- What percentage of records are within SLA?
- How is workload distributed across administrative staff?
- How many records have been completed by each owner?

I created this project to demonstrate how spreadsheet tools can support practical administrative work beyond basic data entry.

The focus is on maintaining clean and standardized records, identifying items that require attention, monitoring processing deadlines, and converting operational data into a concise reporting view.
