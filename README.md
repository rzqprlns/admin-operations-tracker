# Admin Operations Tracker

An Excel-based administrative operations tracker designed to simulate how administrative records can be validated, monitored, and summarized for day-to-day operational reporting.

> **Project type:** Self-initiated portfolio project using synthetic administrative data.

## Overview

Administrative work is not only about entering data. Records also need to be standardized, checked for completeness, monitored against deadlines, and summarized into information that can be used for follow-up.

This project simulates an administrative workflow for tracking incoming documents from the moment they are received until they are completed.

The workbook contains **120 synthetic administrative records** and an interactive monitoring dashboard.
